Services

Every layer of the estate, one accountable team.

Seven services that cover the physical layer, the security perimeter, the cloud edge, and the pipeline that keeps them consistent. Each one is delivered by the engineers who designed it.

01

Network & Security Consultation

Independent advisory for organisations running Cisco and Fortinet estates. We audit what is deployed, map it against how the business actually operates, and return a prioritised plan that separates what must change now from what can wait. No product is recommended before the requirement is written down.

  • Infrastructure audit and gap analysis
  • Zero-trust segmentation design
  • Firewall policy review and hardening
  • SD-WAN architecture (Viptela, FortiSD-WAN)
  • Remote access design (AnyConnect, FortiClient)
  • IPS/IDS tuning and false-positive reduction
  • Wireless security and NAC strategy
  • High-level and low-level design documentation
AssessmentZero TrustSD-WANHardening

02

Managed Security

A security operations capability without the headcount. We run Splunk-based detection, own the alert queue around the clock, and take incidents through containment, eradication, and a written post-incident report. Findings close with evidence, not with a status change.

  • Splunk SIEM implementation and detection tuning
  • 24/7 monitoring, triage, and escalation
  • Incident response and digital forensics
  • Firewall management (Cisco FTD/FMC, FortiGate)
  • Vulnerability assessment and penetration testing
  • Endpoint detection and response rollout
  • Security policy and standards development
  • POPIA and ISO 27001 evidence reporting
SIEMFTD/FMCFortiGateMXDR

03

Network Infrastructure

Campus and branch networks designed to stay up on their worst day. We size for peak rather than average, build redundancy into the gateway and the uplink, and hand over addressing plans and diagrams that still match the estate a year later.

  • Enterprise LAN and WAN design
  • VLAN segmentation and inter-VLAN routing
  • Advanced routing: OSPF, EIGRP, and BGP
  • High availability with HSRP/VRRP and LACP
  • Wireless design and site survey (Aruba, Cisco, Ubiquiti)
  • Quality of service for voice and video
  • Multi-vendor integration and migration
  • Monitoring with SNMP, NetFlow, Grafana, ThousandEyes
CiscoArubaMikroTikWireless

04

Cloud & SD-WAN

Hybrid estates where the cloud footprint and the physical network are designed together rather than bolted to each other. Environments are provisioned from Terraform, so what runs in production matches what is committed to the repository.

  • AWS VPC architecture and workload migration
  • Azure virtual networks and ExpressRoute
  • Hybrid connectivity and site-to-site VPN
  • SD-WAN overlay design and staged rollout
  • Infrastructure as Code with Terraform and CloudFormation
  • Cloud security posture and governance
  • Cost optimisation and rightsizing reviews
  • Disaster recovery and business continuity design
AzureAWSTerraformSD-WAN

05

Network Automation

Configuration managed the way software is managed. Changes are written as code, reviewed, tested against a virtual copy of the network, and released through a pipeline — so a change window becomes a merge rather than a late night.

  • Ansible playbook and role development
  • pyATS and Genie automated test suites
  • GitHub Actions and GitLab CI pipelines
  • Python tooling and REST, NETCONF, gRPC integration
  • Golden configuration and drift detection
  • Automated compliance checking and reporting
  • Generated documentation and version control
  • Controlled change windows with tested rollback
AnsiblepyATSCI/CDPython

06

Smart Building

Building systems and IT on one governed network instead of five unmanaged ones. Cameras, access control, and sensors are segmented away from corporate traffic, documented, and monitored with the same tooling as the rest of the estate.

  • Structured cabling design, installation, and certification
  • IoT network design and segmentation
  • IP-based access control systems
  • IP surveillance and NVR deployment
  • Building management system integration
  • Visitor management solutions
  • Environmental and power monitoring
  • Physical security consulting
CablingIoTAccessSurveillance

07

Microsoft 365 & Productivity

Microsoft 365 deployed with identity and governance decided up front. Conditional access, retention, and data loss prevention are configured against a written policy, and administrators are trained on the tenant they inherit.

  • Tenant design and staged migration
  • Azure AD, conditional access, and MFA
  • SharePoint Online intranet development
  • Teams deployment and governance
  • Power Automate workflow development
  • Power Apps line-of-business applications
  • Exchange Online and email security
  • Data loss prevention and Defender for Office 365
